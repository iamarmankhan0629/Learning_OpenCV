# OpenCV Practice & Projects

This repository contains a collection of Python scripts and Jupyter Notebooks I created while learning Computer Vision with OpenCV.

## Topics Covered

- **Face Detection:** Object detection using Haar Cascades.
- **Image Filters & Blurring:** Applying custom filters and spatial blurring.
- **Contours & Edge Detection:** Identifying object boundaries and shapes.
- **Color Spaces & Thresholding:** Exploring RGB, HSV, LAB, and segmenting specific colors.
- **Geometric Transformations:** Resizing, scaling, cropping, and affine perspective transforms.
- **Histograms:** Histogram equalization and CLAHE for contrast improvement.
- **Video Processing:** Reading, writing, and applying frame-by-frame operations to video files.

## Technologies Used

- Python
- OpenCV (`cv2`)
- Jupyter Notebook
